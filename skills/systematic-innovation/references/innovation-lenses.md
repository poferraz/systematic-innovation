# Innovation Lenses, Reasoning Cells & Mechanism Ledger

## 1. Initial Fluency Depletion (Countering RLHF Homogenization)

Empirical studies ofboth human R&D groups (Rickards, 1975, 1978) and instruction-tuned language models show that the first 2–4 ideas retrieved for any problem are dominated by high-probability memory dumps and conventional internet tropes.

Before populating the portfolio:
1. **Name the Default Tropes (1–2 lines):** Explicitly state the 2–3 most predictable textbook or internet answers for the prompt (e.g., *"Standard reminders / gamified streaks / NFC cap stickers"*, or *"2-2-2 meal rules / moving condiments to crisper drawers"*).
2. **Quarantine or Compress:** Either set those tropes aside entirely or compress them into a single baseline benchmark note so that 100% of the numbered portfolio explores distinct, higher-leverage mechanisms.

## 2. The Seven Reasoning Cells & Ten Lenses

Each Reasoning Cell applies a distinct cognitive operator. Select **3–4 cells** in Quick Mode and **4–6 cells** in Deep Mode so every portfolio spans multiple structural levers.

### Cell A: Reframing & Boundary Shift
- **Lenses:** *Multiple Redefinition* & *System Boundary Examination*
- **Operator:** Rewrite the problem statement across five explicit redefinition modes before generating solutions:
  1. **Analytic:** Where does the bottleneck physically or informationally accumulate?
  2. **Empathic:** Whose cognitive load, dignity, or daily energy is silently taxed by the current design?
  3. **Motivational:** Where does the current reward or accounting system punish the exact behavior the organization asks for?
  4. **Metaphorical:** What natural or infrastructural system exhibits this exact flow pathology (e.g., port demurrage, hospital surgical triage, electric load-shedding)?
  5. **Boundary-Relaxed:** Which upstream supplier, peer, landlord, or bystander already holds the needed information or capacity outside the department's formal boundary?

### Cell B: Preservation & Inversion
- **Lenses:** *Preservation-First Mapping* & *Temporal / Custodial Inversion*
- **Operator:** Lock the non-negotiable assets that already work, then invert **when**, **where**, or **by whom** the remaining action occurs:
  - *Ex-ante $\leftrightarrow$ Ex-post* (verify before transit vs. continuous post-action audit).
  - *Push $\leftrightarrow$ Pull* (broadcasting supply vs. triggering strictly on verified demand).
  - *Centralized queue $\leftrightarrow$ Edge / Point-of-origin resolution*.

### Cell C: Contradiction & Resource Reuse
- **Lenses:** *Dialectical Contradiction Separation* & *Zero-Budget Resource Reallocation*
- **Operator:** State the core contradiction (*"Improving X normally degrades Y"*). Resolve it without adding budget by separating the conflicting requirements:
  - **In Time:** Perform heavy preparation during off-peak troughs so peak-hour execution is zero-friction.
  - **In Space / Scope:** Partition high-risk/high-security zones from low-risk self-service zones.
  - **By Condition:** Apply strict human scrutiny to the 10–15% high-variance tail while automating or pre-certifying the 85–90% standard envelope.
  - **By Waste Conversion:** Use an existing byproduct, idle wait window, or mandatory touchpoint as the carrier for the solution.

### Cell D: Morphological Combination
- **Lenses:** *Morphological Matrix Synthesis*
- **Operator:** Decompose the system into 4–5 independent structural parameters (e.g., *Trigger Signal*, *Verification Medium*, *Custody/Actor*, *Incentive/Settlement*, *Fallback Rule*). Construct novel combinations that cross non-default parameter values without duplicating any parameter row used by another concept.

### Cell E: Far-Domain Analogy & Synectic Excursions
- **Lenses:** *Structural Analogy Transfer* & *Synectic Excursion*
- **Operator:** Map the problem's abstract causal graph (e.g., *asymmetric information at handoff*, *perishable inventory decay*, *multi-authority sequential veto*) to a distant domain with a solved mechanism (e.g., aviation sterile-cockpit checklists, semiconductor wafer binning, maritime container demurrage, clinical surgical timeouts, ecological nurse-plant guilds). Translate the *mechanism*, never just the metaphor.

### Cell F: Provocation & Movement (`Po`)
- **Lenses:** *Formal Provocation (`Po`)* & *Principle Extraction*
- **Operator:** Formulate a deliberate counterfactual stepping-stone (`Po:`) using **Escape** (abolish a taken-for-granted rule), **Reversal** (invert actor roles), **Exaggeration** (scale a limit to 1 or $\infty$), or **Distortion** (invert sequence). Immediately apply **Movement** (*Moment-to-Moment visualization*, *Extract the governing principle*, *Positive aspects under special circumstances*) to land on a safe, actionable mechanism.
- **Safety Boundary:** Never leave a raw provocation as a recommendation; every `Po` must be translated into a constraint-compliant, safe operational mechanism.

### Cell G: Failure, Misuse & Adoption Critics
- **Lenses:** *Pre-Mortem Failure Analysis* & *Problem-Owner Receptivity Audit*
- **Operator:** Stress-test candidate mechanisms against perverse incentives, gaming/fraud, equity blind spots, and organizational antibodies (*"Who loses status, turf, or convenience if this succeeds?"*).

## 3. Parallel Execution & Sequential Fallback

- **When independent sub-contexts are available:** Run selected Reasoning Cells in parallel, each returning 1–2 candidate mechanisms with explicit ledger coordinates.
- **Sequential Single-Context Execution (Default):** Execute the selected cells sequentially inside one response, enforcing the Mechanism Ledger between cells so each subsequent cell is forbidden from repeating an earlier cell's causal lever or stage of action.

### Mandatory Duplicate Collapse Test
Before finalizing the portfolio, compare every pair of candidates `(P_a, P_b)`:
1. **Same Lever + Same Stage = Merge:** If `P_a` and `P_b` both rely on the same causal lever at the same stage (e.g., two variations of commission split percentages, or two forms of paper/QR donor wishlists), merge them into a single richer concept.
2. **Minimum Quality Gate:** Every candidate must satisfy:
   - **Relevance & Constraint Alignment:** Directly addresses the prompt tension and honors all stated budget, staffing, privacy, and statutory constraints.
   - **Causal Clarity:** Explains the concrete step-by-step cause-and-effect chain (`Action $\rightarrow$ Intermediate System Shift $\rightarrow$ Outcome`).
   - **Plausibility & Safety:** Operates within real-world physical, legal, and safeguarding boundaries.
